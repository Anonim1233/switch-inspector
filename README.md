## О проекте

Инструмент для ИТ-поддержки: помогает поддерживать в порядке данные о сетевом
оборудовании магазинов — от учёта коммутаторов до схем наполнения шкафов.

Заменил отчёт, доступный только для чтения: данные редактирует вся команда,
изменения видны сразу, качество заполнения контролируется автоматически.

**Масштаб:** ~1650 коммутаторов · 129 объектов · 12 дивизионов

## Быстрый старт

### Требования

- Node.js 22.5 или новее — сервер использует встроенный модуль работы с базой
- PostgreSQL 13 или новее
- Шрифты с кириллицей: `fonts-dejavu-core` — нужны для PDF-отчёта

### База данных

```bash
sudo -u postgres psql
CREATE USER switch_inventory WITH PASSWORD 'задайте_пароль';
CREATE DATABASE switch_inventory OWNER switch_inventory;
\q
```

### Сервер

```bash
cd backend
npm install
cp ../.env.example .env      # заполнить значения
node server.js
```

Схема базы создаётся автоматически при первом запуске.

Первый пользователь:
```bash
node add-user.js admin ВашПароль "Администратор" developer
```

### Интерфейс

```bash
cd frontend
npm install
npm run dev                  # разработка, порт 5173
npm run build                # сборка для развёртывания
```

В режиме разработки запросы к серверу проксируются автоматически.

### Всё сразу через контейнеры

```bash
cp .env.example .env         # заполнить JWT_SECRET и PGPASSWORD
docker compose up -d
```

Интерфейс будет доступен на `http://localhost:8080`, база создастся
и наполнится схемой автоматически.

### Развёртывание в кластере

```bash
kubectl create secret generic switch-inspector-secrets \
  --from-literal=JWT_SECRET="$(openssl rand -hex 48)" \
  --from-literal=PGPASSWORD='пароль_базы'

kubectl apply -f deploy/kubernetes/
```

Манифесты в [deploy/kubernetes/](deploy/kubernetes/): две реплики сервера
и интерфейса, проверки готовности и живости, ограничения ресурсов.

## Возможности

| Раздел | Что делает |
|---|---|
| **Дашборд** | Показатели по сети, замечания по семи категориям с фильтрацией, PDF-отчёт, загрузка из Excel |
| **Объекты** | Таблица коммутаторов, карточка с правкой и заметками, паспорт объекта, заявки |

**Общее:** вход с подтверждением личности, роли и зона ответственности
по дивизионам, живые обновления между пользователями, светлая и тёмная темы,
работа с телефона.

## База данных

Схема создаётся приложением автоматически при первом запуске. Файлы в
[database/](database/) нужны для понимания структуры и ручной подготовки:

| Файл | Назначение |
|---|---|
| `01-schema.sql` | 11 таблиц с пояснениями |
| `02-indexes.sql` | Индексы под частые запросы |
| `03-constraints.sql` | Внешние ключи и проверки значений |
| `04-check-before-constraints.sql` | Проверка данных перед добавлением связей |

> Ограничения из `03` добавлять **только после** проверки запросами из `04`:
> если в базе есть записи, ссылающиеся на несуществующие, команды завершатся
> ошибкой. В коде приложения этих связей нет — целостность поддерживается
> логикой, чего при нескольких репликах недостаточно.

## Роли и доступ

| Роль | Возможности |
|---|---|
| `viewer` | Просмотр данных, формирование заявок |
| `admin` | Просмотр и редактирование |
| `developer` | Полный доступ: пользователи, дивизионы, отчёты |

**Зона ответственности** — независимое от роли ограничение по дивизионам.
Проверяется на сервере при каждом запросе; в интерфейсе она лишь отключает
недоступные действия.

<details>
<summary><b>О чём стоит знать, прежде чем править код</b></summary>

<br>

- **`mag` хранится без префикса** (`134`), а `sw` — с префиксом (`MAG134_70`).
  Полный вид собирается на лету.
- **Разделитель в именах коммутаторов непостоянен**: в данных встречаются
  и `DS253_66`, и `DS253-67`. Сопоставление приводит обе стороны к единому виду.
- **Формула подсчёта замечаний продублирована** на сервере (`ISSUE_COUNT_SQL`)
  и в интерфейсе (`domain/issues.js`). При изменении править нужно оба места,
  иначе цифры в отчёте разойдутся с экраном.
- **Сохранение шкафа заменяет содержимое целиком** — при одновременном
  редактировании одного шкафа двумя людьми второе сохранение затрёт первое.
- **Обращения к хранилищу браузера обёрнуты** в перехват ошибок: приложение
  может открываться там, где они запрещены.
- **Токен потока обновлений передаётся в адресе**, а не заголовком: браузерный
  механизм событий не умеет отправлять свои заголовки.

</details>
